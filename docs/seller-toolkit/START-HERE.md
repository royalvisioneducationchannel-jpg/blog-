# Seller Toolkit — Claude Code build pack

Ye pack WordPress par seller-tools SaaS banane ke liye hai. Isay Claude Code ke project folder mein rakho.

## Istemal

1. `MASTER-PROMPT.md` Claude Code ko do. Is mein tamam requirements aur 14 phases hain.
2. Kaho: **“Read MASTER-PROMPT.md completely. Start Phase 00 only. Inspect the existing Hostinger/WordPress setup before changing anything.”**
3. Phase complete ho to us ka result/screenshots dekho. Phir kaho: **“Continue with the next phase from MASTER-PROMPT.md. Read PROJECT-STATUS.md first, preserve completed work, implement and test this phase.”**
4. Nayi Claude chat mein bhi MASTER-PROMPT.md aur PROJECT-STATUS.md parhwao.

## Tumhein kis waqt kya dena hoga

- Phase 00: Claude mein Hostinger/WordPress connection authorize karo. Chat mein passwords ya secret keys paste na karo.
- Phase 01: final brand name, business country, currency aur license budget confirm karo. Seller Toolkit working name hai.
- Phase 02: homepage aur portal design preview dekho.
- Phase 07: payment merchant account, approved prices aur sandbox access configure karo.
- Phase 09: sender email/domain aur, agar chaho, WhatsApp/SMS provider configure karo.
- Phase 10: jis paid API ko use karna hai us ki key secure settings mein enter karo.
- Phase 13: final domain, business policies aur live launch approve karo. AdSense account/identity steps khud complete karo.

## Kya expect karna hai

Existing tools dobara scratch se banane ya delete karne ka order nahi hai. Pehle audit, phir improvements. Free tools traffic aur usefulness ke liye; paid plans saved work, management features aur real paid processing ke liye. Actual subscriptions tabhi sell hon jab promised features ready hon.

AdSense approval, search ranking aur earning guaranteed nahi. Dummy/staging domain development ke liye hai; final public domain par content aur policies review karke application prepare karni hai.

Elementor Pro aur WooCommerce Subscriptions jaise paid products ki valid licenses alag chahiye ho sakti hain. Payment provider ki fees aur API costs bhi separate hain.

## Phases

00. Hostinger connection, inventory, backup and staging
01. Existing-tool audit, market validation and product scope
02. Brand system and homepage/portal design previews
03. WordPress foundation and editable Elementor components
04. Public homepage, tool directory and sales pages
05. Existing tools and advanced workflow improvements
06. Accounts, customer portal and entitlements
07. Checkout, subscriptions, renewals and payment handling
08. Seller operations workspace
09. Admin CRM and renewal communications
10. Paid API integrations, quotas and cost controls
11. Original content, trust, SEO and AdSense readiness
12. Security, billing, usability and performance testing
13. Final-domain launch, AdSense application preparation and handover

Har phase ka detailed prompt, scope aur acceptance checks MASTER-PROMPT.md mein hain.
